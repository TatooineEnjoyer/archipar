# ARCHIPAR

Статический сайт на Next.js. SSR и серверные API не требуются.

## Локальная проверка

```bash
npm ci
npm run build
```

После сборки готовый сайт находится в папке `out`.

## Timeweb Cloud

- Тип приложения: Frontend
- SSR: выключен
- Команда сборки: `npm run build`
- Директория результата: `out`
- Версия Node.js: 22 или 24

Папку `public` удалять нельзя: в ней находятся изображения, логотипы и hero-видео.

## Форма заявки

Проект собирается без Supabase и без серверных переменных. Для реальной отправки формы можно добавить публичную переменную сборки:

```text
NEXT_PUBLIC_LEADS_ENDPOINT=https://ваш-внешний-обработчик.example/leads
```

Endpoint должен принимать JSON через POST. Без переменной форма работает в демонстрационном режиме и не ломает статический сайт.

## Hero-видео

Видео в `public/videos` уже подготовлены как ping-pong: движение вперёд, затем назад. Повторно обрабатывать текущие файлы не требуется.
